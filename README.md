Welcome to **TradeSage**, the premier real-time stock market analytics platform designed to give you an edge in today's fast-paced financial markets. TradeSage combines live data streams, cutting-edge machine learning predictions, and real-time sentiment analysis into a sleek, premium, and highly responsive dark-mode interface.

## 🚀 Key Features

*   **Live Market Data**: WebSocket integration delivers instantaneous price updates, ensuring you never miss a tick.
*   **AI-Powered Predictions**: Integrated machine learning pipeline forecasts short-term price movements with dynamic visual indicators.
*   **Real-Time Sentiment Analysis**: Scrapes and analyzes live news to give you a pulse on market sentiment (Bullish, Bearish, or Neutral) via an intuitive gauge component.
*   **Sleek Glassmorphism UI**: A visually stunning, modern dark-mode aesthetic with vibrant neon accents, built for professional traders who demand both performance and style.
*   **Instant Trading Signals**: Automated buy/sell signals generated from a confluence of technical indicators and sentiment scores.

## 🛠 Technology Stack

*   **Frontend**: React, Vite, Vanilla CSS with custom design tokens for a premium look.
*   **Backend**: FastAPI, Python, WebSockets for high-performance data orchestration.
*   **Machine Learning**: Scikit-Learn / PyTorch pipelines for live inference.
*   **Data Integration**: Real-time APIs for market data and financial news.

## 🌟 Getting Started

1.  **Clone the repository.**
2.  **Start the Backend**: Navigate to the `backend` directory, install dependencies, and run the FastAPI server (e.g., `uvicorn app.main:app --reload`).
3.  **Start the Frontend**: Navigate to the `frontend` directory, run `npm install`, followed by `npm run dev`.
4.  **Trade Smarter**: Open your browser and experience TradeSage.
